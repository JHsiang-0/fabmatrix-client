# SYNC-001 选择性界面集成设计

## 1. 分支拓扑

```text
27bcc42 共同基线
├── 2896a55  本地功能基线
│   └── SYNC-001.x 选择性视觉适配
└── 30adedc  远程界面分支
```

集成分支建议命名为 `integration/ui-sync-30adedc`，并从本地 `2896a55` 创建。最终只推送新的集成分支，待验收后再由团队决定是否合入功能分支。

## 2. 分层策略

### 2.1 结构和视觉层

优先从远程提交中提取模板结构、TDesign 组件属性、CSS 变量、间距、表格密度、悬停反馈和响应式规则。页面中的数据计算、事件处理、请求调用和状态合并以本地为准。

远程页面文件是大范围重写，不能简单 cherry-pick 后依赖冲突解决器完成集成；需要逐段比较并手工适配。

### 2.2 业务保护层

以下模块属于保护区，除非任务明确给出契约审计结论，不允许使用远程版本覆盖：

```text
src/api/
src/stores/
src/utils/
src/components/file/
src/views/FileLibrary.vue
src/views/PrinterManage.vue 中的监控、实时合并和权限逻辑
src/views/Dashboard.vue 中的 REST/WS 统计和断线处理
tests/printerMonitoring.test.js
```

远程分支已经删除或回退了部分监控、文件夹、批量移动、上传和人工核对 API；这些差异必须视为业务回退风险，而不是普通合并冲突。

### 2.3 状态和数据来源

- 页面展示继续使用本地 API、Store 和 data adapter。
- 业务状态、通信状态、监控开关、实时连接状态不得使用样式分支互相推导。
- 断线时保留最后已知数据；视觉层只增加陈旧/断开提示，不清空业务字段。
- 错误提示统一复用项目消息工具，不在页面内新增独立错误处理。

## 3. 页面集成顺序

```text
基线冻结
  ↓
防回退门禁
  ↓
应用壳/导航
  ↓
打印机中心 ──┐
             ├── 总览与全屏看板
任务中心 ────┤
批量派发 ────┤
文件库 ──────┤
个人中心/审计 ┘
  ↓
全量回归与桌面验收
```

打印机中心先于看板，因为看板依赖打印机状态、连接状态和网格数据的既有契约。

## 4. 远程改动分级

### 可优先吸收

- 纯 CSS、TDesign 组件外观和间距调整。
- 表格 hover、按钮主题、分页区域和卡片布局。
- 页面标题、工具栏、空态和响应式容器。

### 必须逐项审查

- 打印机自动筛选和未分配设备 Drawer。
- 任务页面和批量派发流程重构。
- REST/WS 看板合并、网格配置、状态统计。
- 文件库的目录树和上传界面重构。

### 明确延后

- 动态 30×60 网格、过道布局和后端持久化。当前后端仍存在固定坐标约束，另立 `SYNC-002`。

## 5. 回滚策略

- 集成前创建日期化备份分支。
- 每个 `SYNC-001.x` 独立提交。
- 已提交的集成改动使用 `git revert` 回退，不使用 `reset --hard` 覆盖共享分支。
- 若单个页面验收失败，只回退该页面提交，不回退本地功能基线。
