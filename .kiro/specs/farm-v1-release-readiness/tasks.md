# FabMatrix 1.0.0 准正式版发布整改任务

状态：待实施
执行原则：按依赖顺序逐项完成；每个子任务独立验证、独立提交，不得跳过 P0 发布阻断。

## [x] R100-01 统一版本和应用身份

优先级：P0

完成日期：2026-09-14

范围：前端版本、Electron appId、后端 Maven、服务器安装器、托盘程序、安装包命名和版本展示。

工作内容：

- 将全部数字版本统一为 `1.0.0`，Windows 文件版本为 `1.0.0.0`。
- 移除后端 `SNAPSHOT` 和安装器旧 `2.0.0` 默认值。
- 更换 `com.example.*` 为 FabMatrix 正式唯一应用标识。
- 增加跨项目版本一致性检查。

验收：所有界面、日志、健康接口、文件属性和安装包版本一致；版本不一致时发布检查失败。已统一为 `1.0.0` / `1.0.0.0`，应用标识已替换为正式值，前后端版本契约检查、前端测试/构建、后端测试和 Windows 安装器契约验证通过；真实安装包安装验收仍留待 R100-10。

## [x] R100-02 保护首次管理员初始化

优先级：P0
依赖：R100-01

完成日期：2026-09-14

范围：后端 setup 契约、Local 配置、Windows 安装器、托盘初始化入口和前端初始化页。

工作内容：

- 实施一次性 bootstrap token。
- 原子完成首个 ADMIN 创建和 setup 关闭。
- 防止局域网抢占、重复初始化和旧 token 重放。
- 覆盖完全卸载后的重新初始化。

验收：非服务器本机持有者不能创建首个管理员；初始化完成后接口不可再次使用。已增加一次性 30 分钟 bootstrap 凭据、loopback 访问限制、持久化 setup latch、过期/缺失凭据自动轮换和 Local schema 兼容迁移；前后端测试、安装器契约测试和构建通过，真实 Windows ACL/安装现场验收留待 R100-10。

## [x] R100-03 实施 JWT 与 WebSocket 会话吊销

优先级：P0
依赖：R100-02

范围：用户模型与迁移、JWT、认证过滤器、WebSocket、用户管理和前端退出反馈。

工作内容：

- 引入会话版本并在改密、禁用、角色变化时递增。
- REST 每次请求核对当前用户状态、角色和会话版本。
- WebSocket 在过期或会话失效后主动关闭。
- 保护最后一个启用 ADMIN。

完成日期：2026-09-14

验收：改密、禁用或降权后，旧 REST/WS 会话立即不可用。已增加 tokenVersion 会话版本、REST 当前用户校验、WebSocket 心跳失效检测与 1008 主动断开、前端失效后清理登录态，并保护最后一个启用 ADMIN；SQLite/MySQL 迁移与前后端测试通过，真实多进程/现场 WebSocket 验证留待 R100-10。

## [ ] R100-04 修复打印控制一致性

优先级：P0
依赖：R100-03

范围：打印任务状态机、设备控制、打印机锁、监控任务、审计和相关后端测试。

工作内容：

- 统一启动、取消、暂停、恢复、急停和监控锁边界。
- 增加 CAS、commandId、锁续租和 fencing 语义。
- 将不确定结果收敛到 `RECONCILING`。
- 防止并发和重试造成重复物理动作。

验收：并发启动/取消只有一个合法结果；设备动作与数据库异常场景可恢复、可审计。

## [ ] R100-07 强化服务器安装、升级和完全卸载

优先级：P0
依赖：R100-01、R100-02、R100-06

范围：Inno Setup、WinSW、服务配置、托盘状态、端口元数据和安装器测试。

工作内容：

- 固定端口 `28081`，禁止回落到 `8080`。

- 验证升级安装保留数据、完全卸载清空状态。

验收：安装器不再出现虚假成功；四种安装/卸载路径均有自动化或受控验收记录。

优先级：P1

优先级：P1
