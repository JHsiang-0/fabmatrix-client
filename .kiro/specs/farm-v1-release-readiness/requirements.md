# FabMatrix 1.0.0 准正式版发布整改需求

版本：1.0.0
任务标识：R100
任务类型：前后端、Electron 与 Windows 安装器联合整改
状态：代码整改基本完成；R100-07 与真实环境验收待完成
涉及项目：`fabmatrix-client`、`fabmatrix-server`

> 版本归属：本规格是当前 `1.0.0` 准正式版的 R100 发布门禁。“farm-v1”是历史规格目录命名，不表示产品 v1；API `/api/v1` 也只是兼容路径。历史 v2 功能是否进入本版本，以本规格的发布范围和验收结果为准。

## 1. 发布范围

本任务只面向以下部署形态：

- 一台 Windows Local Server；
- 多台 Windows Electron 客户端；
- 服务默认端口 `28081`；
- 本地数据库与本地文件存储；
- 厂内局域网部署。

Server Edition、MySQL、Redis、RustFS 和 Docker 发布不属于 1.0.0 准正式版交付范围，其已知问题保留至独立任务处理。

## 2. 版本要求

- 前端、Electron、后端、托盘程序和安装器对外版本统一为 `1.0.0`。
- 后端 Maven 版本不得包含 `SNAPSHOT`。
- Windows 文件版本使用 `1.0.0.0`。
- 客户端显示文案为 `v1.0.0 准正式版`。
- 安装包名称固定为 `FabMatrix-Client-Setup-1.0.0.exe` 和 `FabMatrix-Server-Setup-1.0.0.exe`。
- 候选发布标签使用 `v1.0.0-rc.N`，正式确认后使用 `v1.0.0`。
- Electron 客户端和服务器托盘使用正式、唯一的应用标识，不得继续使用 `com.example.*`。

## 3. 功能与安全需求

### R-R100-01 首次管理员初始化安全

- 空数据库初始化不得仅依赖“当前没有用户”。
- 首次管理员创建必须校验安装时生成的一次性初始化凭据。
- 初始化凭据只能在服务器本机安全获取，使用后立即失效。
- 初始化完成后服务端永久关闭首次管理员入口，除非执行明确的完全卸载并清理数据。
- 局域网其他设备不得抢先创建首个管理员。

### R-R100-02 会话与权限即时失效

- 修改密码、禁用账号或改变角色后，旧 JWT 必须立即失效。
- REST 请求必须核对当前用户状态和会话版本。
- WebSocket 必须在令牌过期、用户禁用或权限变化时断开。
- 系统必须始终保留至少一个启用状态的 ADMIN。

### R-R100-03 打印控制一致性

- 启动、取消、暂停、恢复、急停和监控更新必须共享同一打印机互斥边界。
- 所有设备命令必须具备幂等命令标识。
- 任务状态更新必须使用状态条件或 CAS，禁止非法并发跃迁。
- 设备动作成功但数据库写入失败时，任务必须进入可恢复的核对状态。
- 不得向同一打印机重复下发启动命令。

### R-R100-04 V1 功能边界

- 1.0.0 不发布批量派发功能。
- 前端入口、直接路由和后端接口必须由同一功能开关控制。
- 功能关闭时后端返回稳定的 `FEATURE_DISABLED`，不能只隐藏前端按钮。
- 保留 V3 代码和测试，但批量 Confirm 必须拒绝预览判定为不可执行的项目。

### R-R100-05 本地文件完整性

- 上传前按文件大小、临时空间和安全余量检查磁盘容量。
- 空间不足时必须在写入前拒绝，不得留下半文件。
- Local 缩略图接口必须返回真实缩略图及正确 MIME 类型。
- 删除文件不得出现“磁盘对象已删除、数据库记录仍存在”的不可恢复状态。
- 日志必须轮转并限制总容量；运行时不得重新生成无用途的 `backup/`。

### R-R100-06 安装、升级与完全卸载

- 安装成功必须以 `28081` 端口监听且 `/actuator/health` 返回健康为准。
- 服务启动失败时安装器必须显示有效日志并报告失败。
- 安装前应停止旧服务、托盘、Java 运行时及占用安装文件的进程。
- 安装器不得静默回退至 `8080`。
- 升级安装保留数据库和文件。
- 卸载提供“保留数据”和“完全卸载”两个明确选项。
- 完全卸载后重新安装必须进入首次管理员初始化。

### R-R100-07 Electron 安全

- 生产窗口禁止导航至未授权来源。
- IPC 必须校验调用窗口和 `senderFrame` 来源。
- 生产环境不得暴露本地用户目录等诊断信息。
- 应用入口必须配置可执行的 CSP。
- Mock 模式和 E2E 绕过不得在已打包应用中生效。
- Mock 安装包必须与正式安装包使用不同身份和输出目录。
- 上传页面卸载时必须中止未完成请求。

### R-R100-08 网络连接安全

- API 与 WebSocket 默认端口均为 `28081`。
- WebSocket 地址默认跟随 API 地址变化，同时允许用户显式独立配置。
- 非本机明文 HTTP/WS 必须提供明确风险提示或受部署策略限制。
- Token 不得写入客户端日志、服务访问日志或错误报告。

### R-R100-09 错误语义

- 400：参数错误；401：未认证；403：无权限；404：资源不存在；409：并发冲突；422：业务状态不可执行；503：设备或依赖不可用；500：未预期异常。
- 前端不得把预期业务错误统一显示为“系统内部异常”。
- 用户提示不得暴露 SQL、Java 堆栈、文件系统路径或凭据。
- 服务日志和前端错误反馈通过 `traceId` 关联。

### R-R100-10 发布门禁

- 正式发布必须执行前端测试、lint、构建和 Electron E2E。
- 必须修复现有 Electron dist E2E 失败。
- 必须执行后端完整测试和 Windows 安装器契约测试。
- 必须验证实际 `win-unpacked` 或安装后的 EXE，而不是仅验证开发模式。
- 必须覆盖首次安装、升级、保留数据卸载、完全卸载四条路径。
- 发布产物不得包含 Mock、开发凭据、本地环境文件或测试数据。
- 产物必须生成 SHA-256 校验文件。

### R-R100-15 已登记打印机地址恢复

- ADMIN 可从打印机管理页主动同步已有设备 IP；OPERATOR 不展示入口且不查询管理员任务。
- 普通刷新只读取列表；同步范围由后端配置，前端展示范围和逐台更新/未找到/冲突等结果，不导入未知设备。
- 异步任务每 2 秒串行查询；页面重新进入恢复 RUNNING，完成刷新列表，失败提供重新查询/启动，卸载清理定时器和旧响应。
- 保留设备名称、编号、位置、任务关联和监控开关；不回显 MAC、API Key 或其他内部凭据。
- 真实关机换 IP 后重新开机的恢复结果必须在厂内网络验收。

## 4. 非功能要求

### R-R100-16 打印历史导出

- ADMIN 和 OPERATOR 均可选择 Excel/PDF；权限由后端执行，OPERATOR 仅本人任务。
- 导出弹窗初始化列表已应用条件，可独立编辑终态状态、文件、设备、ADMIN 创建人和结束时间范围（秒级），直接导出全部分页；不改变列表，不要求先查询列表，不显示旧列表条数作为新范围条数，支持重置全历史和恢复列表条件。
- 使用统一鉴权请求，不把 JWT 放入 URL；二进制成功与标准 JSON 错误分别处理，限额 422、权限 403 和认证 401 不产生假文件。
- 重复点击、取消、卸载和会话/角色切换受保护，Blob URL 在浏览器消费下载后释放；文件名支持中文并限制为安全 basename。
- Excel 明细为第一张且默认激活的工作表，13字段和所有匹配明细完整保留；统计为第二张表。Mock 生成有效 XLSX/PDF 样本并在正式构建中排除，实际读回下载的 XLSX 验证工作表顺序、激活和真实行；浏览器实测独立筛选、列表不变、两格式、全部分页、操作员边界和超限错误。

- 不改变现有文件、任务、打印机和用户业务数据语义，必要的数据结构变化必须提供升级迁移。
- 所有设备控制整改必须保留审计记录和操作人信息。
- 所有安全功能必须同时覆盖 ADMIN 和 OPERATOR。
- 前端继续使用 TDesign 官方组件和现有设计语言。
- 任何未通过真实设备验证的打印控制能力必须在验收记录中标记为 `NOT RUN`，不得声明完成。

### R-R100-16-UI 导出弹窗布局维护

- 使用 TDesign 默认 Form/Grid/Space/Typography/Dialog 组件和原生页脚；不新增弹窗独立 CSS、颜色、圆角或控件覆盖样式，删除原有导出专用样式。
- 标签置于控件上方，桌面普通筛选与格式选择按两列排列，时间范围独占一行；窄屏使用组件默认响应式单列布局，低高度允许滚动且取消/下载始终可到达。
- “清空筛选”清除导出条件并选中全部终态；“使用列表筛选”复制最近成功应用的列表条件，不能取尚未查询的表单值。两者分别提供说明，保持已有权限、加载、日期秒级精度和取消保护。

## 5. 总体验收标准

- 全部组件、安装包、健康接口和界面显示统一版本 `1.0.0`。
- 局域网用户不能抢占首次管理员初始化。
- 改密、禁用和降权后旧 REST/WS 会话立即失效。
- 重复或并发操作不会向打印机重复下发命令。
- V1 无法通过前端或直接调用使用批量派发。
- 本地文件上传、缩略图、删除和磁盘不足场景不会产生不可恢复数据损坏。
- 安装器只在服务真实健康后报告成功，完全卸载后不保留旧账号和端口状态。
- 正式安装包无法进入 Mock/E2E 模式。
- 所有发布门禁通过并形成可追溯验收记录后，方可生成 `v1.0.0-rc.1`。
