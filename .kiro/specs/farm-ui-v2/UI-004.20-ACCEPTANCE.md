## 验收结论

- 直接 `fileId` 访问统一验证完整祖先链：记录存在、父级为文件夹、无循环、最多两级、visibility 一致、PRIVATE 根及整链归属合法；异常路径拒绝预览、缩略图、下载、创建任务、任务查询、删除和批量操作。
- 批量派发预览/新计划创建的文件使用按 `PUBLIC || owner || ADMIN` 校验；既有计划确认严格按 `plan.createdBy || ADMIN` 校验，公共文件不会转移计划所有权。确认阶段重新校验实际请求明细。
- ADMIN 可跨创建者管理和移动 PUBLIC 文件/目录；PRIVATE 资源仍受所有者边界约束。前端目标选择和 Mock capability 与后端一致。
- MySQL 与 Local/SQLite 迁移把默认目录完整子树固定为 PRIVATE；根文件归档仅处理旧/PRIVATE，PUBLIC 根文件跨重复迁移和重启保持根级。两条 15 脚本及 Local 启动诊断覆盖公共候选后代、孤儿、循环、超深、同级目录重名、父子 visibility 冲突和非文件夹父级；同名诊断只按真实目录命名空间判断。Local 启动异常安全阻断且迁移可重复。SQLite 原生不支持条件 `ADD COLUMN`，因此由 `LocalSchemaMigration` 负责可重复 schema 补齐，手工 SQL 仅用于列已补齐后的回填/诊断。
- Mock 分页按 `canReadFile` 过滤；第三用户可读取公共文件，上传者可删除，非上传者拒绝删除。
