# Ardot + TDesign 前端原型 Kiro 任务清单

版本：1.0.0 准正式版
规格：`farm-ardot-tdesign-prototype`
状态：原型初版已完成（待响应式验收与评审）
前置说明：本任务只产出可评审的 Ardot 原型和编码交接资料，不直接修改 Vue、API 或后端。

## 执行规则

- 以当前 Vue 路由、页面和组件为业务基线。
- 所有常用交互控件优先使用 Ardot `TDesign for web` 真实组件实例。
- 保留原手动画稿作为备份，未经评审不得删除。
- 每完成一个页面，必须进行 1440×900 和 800×560 两档检查。
- 发现组件库中只有图标或子组件时，必须在交付说明中标注，不得冒充完整业务组件。

## 验收标准

- [ ] AC-01 任何核心页面都不是零散组件板，而是具有应用壳、页面标题、工具栏、内容区和状态反馈的完整业务画板。
- [ ] AC-02 核心交互控件均可通过 Ardot 属性面板确认来自 TDesign for web，无法提供完整实例的表格按子组件组合并有说明。
- [ ] AC-03 打印机管理、文件库、任务中心、全屏看板及其抽屉/弹窗均有正常态和至少一种异常态。
- [ ] AC-04 页面标题统一为“嘉东三维联动3D打印机实时控制系统”，不出现未经业务确认的硬编码车间名称。
- [ ] AC-05 1440×900 和 800×560 两档下无关键内容遮挡，打印机表格、扫描结果、文件树和抽屉满足滚动/固定列要求。
- [ ] AC-06 原型交付资料包含 Ardot 链接、页面清单、组件映射、状态清单、截图和待编码项。
- [ ] AC-07 原型评审通过后才能进入 Vue 编码；本任务完成不代表产品代码已经修改。
