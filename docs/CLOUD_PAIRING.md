# 手机扫码连接云端

本地管理员入口：设置 → 云端连接 → 手机扫码配对。首次填写部署者提供的 Cloud API、MQTT TLS 地址和必要的 CA 公共证书，生成十分钟二维码。手机在「我的 → 扫码连接现场服务器」扫码，核对编号、选择农场并确认。桌面每三秒查询配对结果，成功后展示组织/农场；仍须显式开启数据上报。

二维码仅保留于页面内存，不写入 localStorage/sessionStorage，不包含本地登录或网关领取凭据。关闭窗口停止查询，Server 临时会话仍保留至过期，可重新进入恢复；取消会撤销当前会话，过期可重新生成。账号变更、页面卸载后停止处理异步结果。当前已绑定时不展示扫码入口，避免意外替换生产网关。

未连接 Cloud 时 Server + Client 独立使用。本地和 Cloud 账号仍分开，手机不接触现场打印机。Cloud 需升级 V18，Server 需包含 pairing 接口。旧绑定码入口保留，系统信任/自建 CA 继续执行 TLS 校验。

验证：Node 全量测试、lint、正式构建与 Playwright「云端连接」用例。二维码浏览器截图为模拟服务验收，不代表手机真机扫码。
