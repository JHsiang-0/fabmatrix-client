# 云端只读看板

## 当前产品边界

2026-11-05 按用户确认的 [ADR 0011](../../../Java/fabmatrix-cloud/docs/decisions/0011-local-production-and-cloud-reporting.md)，Client 作为独立本地生产客户端，云端入口、路由、页面和专属会话模块已移除。当前 Cloud + 手机 App 提供远程业务，Server 使用可选上报模块。下文为原 Client 云看板的历史实现与验收记录。

## 历史记录

入口为主界面侧栏“云端平台 → 云端设备看板”，也可从服务器连接页进入，路由 `/cloud`。主界面顶部“云端管理”可直达管理页，未登录时先进行云端登录。填写 HTTPS 云服务根地址，独立云账号登录后选择组织/农场。手机宽度采用设备卡片，桌面采用表格。组织、农场、成员和网关管理现已提供 [独立管理页面](CLOUD_MANAGEMENT.md)。

云与局域网凭证、会话和错误清理彼此独立：云 Token 仅在内存，密码提交后清空；只保存服务地址，刷新网页需重新登录云端。cloud API 使用现有 request.js 导出的独立 Axios 工厂，不复用局域网拦截器或 JWT，也不允许 cookie 凭证。退出/切换范围时取消旧请求，以请求代次防止旧响应或旧 401 覆盖当前状态；云 401 保留本地已保存会话。

云路由跳过局域网认证恢复和 WebSocket，返回局域网页面仍遵循原有认证规则。每 5 秒刷新，后台标签页暂停，卸载取消请求。显示网关在线、设备状态、观察时间；云标记过期、请求失败或超过 15 秒没有刷新成功均灰显，不能把缓存当作实时状态或据此认定设备可操作。

云服务必须配置网页的精确 CORS Origin，API 和 MQTT 使用受信 TLS。Electron file 来源可能为 null，仅在受控部署显式允许 null；不使用通配符或关闭证书校验。当前页面限制远程 HTTPS（字面 loopback 可 HTTP 调试），不会自动在局域网与云之间迁移请求。

验证：`npm run test:cloud`、`npm test`、`npm run lint:check`、`npm run build`、`npm run build:desktop`；浏览器测试 `npm run test:e2e -- --grep 云端看板` 使用模拟云 API，验证身份隔离、过期展示、手机布局和云 401 保留本地会话。模拟测试不能证明公网部署或真实设备同步已验收。

2026-10-30 本地结果：444 项 Node 测试、lint、Web/desktop/mock 构建通过；最终完整 browser 回归 32 项通过、4 项按默认批量派发功能开关跳过。中途两个失败用例在修改前快照与当前版本定向复测均通过，最终完整重跑也通过。构建仍有现有包体大小警告，未重新生成安装包、推送或部署。
