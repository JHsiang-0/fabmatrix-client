# 组织与农场管理

## 当前产品边界

2026-11-05 按用户确认的 [ADR 0011](../../../Java/fabmatrix-cloud/docs/decisions/0011-local-production-and-cloud-reporting.md)，Client 作为独立本地生产客户端，原云端组织、农场、成员、网关和审计页面已移除。远程管理由 Flutter 手机 App 和 Cloud 承担。下文为原 Client 云端功能的历史实现及验收记录。

## 历史记录

云端看板登录后点击“组织与农场管理”，进入 `/cloud/manage`。使用独立云会话和 Cloud API，云路由跳过局域网登录恢复。需要配套 Cloud V17。

## 主界面入口

局域网主界面侧栏的“云端平台”分组提供“云端设备看板”和“组织与农场管理”。宽于 1024 像素的窗口顶部还有“云端管理”按钮；较窄窗口通过侧栏进入。

直接打开管理页面时，尚未登录云端的用户先进入云端登录页，成功后自动进入管理页。临时密码账号先完成改密并重新登录。返回目标仅允许固定的管理页面，不能通过查询参数跳转任意地址。

云端看板和管理页均有“返回局域网”按钮，返回主界面时复用原局域网会话；局域网登录过期时走原有登录校验。局域网岗位不决定云端组织角色，云端接口继续逐次检查权限。

入口补齐后通过 461 项 Node 测试、lint、42 项浏览器回归，4 项按既有开关跳过；release gate 的正式 / Mock / desktop 构建、Electron dist 测试及安全扫描通过。首次全量回归曾出现表格勾选失败，该用例连续三次复测及最终全量回归通过。

## 页面

- 组织概览展示说明、所有者、创建时间、当前岗位、可访问农场数量与设备统计，管理者还可查看成员数量。
- 农场概览展示说明、地点和创建时间，以及网关、在线、打印、暂停、故障、离线、未知设备统计。统计来自服务端完整清单，覆盖列表分页之外的设备。
- OWNER / ADMIN 可创建农场及编辑组织和农场资料。OWNER 可申请删除空组织。农场删除由后端校验网关和成员授权，冲突原因直接展示。
- 组织成员页支持创建、角色调整、受限密码重置和移除；农场成员页管理显式读取权限。OWNER / ADMIN 自动有农场访问权。
- 网关页支持创建、名称修改、重绑定、吊销和受保护删除。重绑定及吊销有影响说明和二次确认。绑定码仅在当前窗口、有效期内展示，关闭、切换范围、退出账号后清空。
- 操作记录按动作前缀筛选及分页，沿用后端 snake_case 审计契约。
- 临时密码账号先在云端看板修改密码，再重新登录进入业务页面。

当前在线与未知统计可能重叠，未知包含陈旧、未监控及在线但操作状态不完整的记录。页面显示读取时快照，可手动刷新。设备物理控制属于独立后续范围。

## 验证与部署

新增 Node 测试覆盖取消后的迟到响应、范围切换、绑定码清除、401、权限刷新、临时密码流程和错误脱敏。Playwright 使用合成云接口，覆盖资料编辑、删除保护、成员授权、绑定码、查看员和窄屏布局。发布前执行 lint、Node 全量、浏览器和 release gate，后者覆盖正式、Mock、桌面构建及 Electron 产物测试。

本轮在原工作区开发，Cloud 服务、现场 Server、真实打印机和手机安装均等待代码验收后安排升级。所有权转移、既有账号邀请、农场归档和网关级授权留待后续。

2026-11-05 已通过 461 项 Node 测试、lint、40 项浏览器回归，4 项按既有功能开关跳过。release gate 的正式 / Mock / desktop 构建、Electron dist 测试及产物扫描通过。Windows 安装包已构建，复用现有品牌 ICO 以适配本机打包环境；已核对安装包内含管理页面资源。App 配套实现见手机仓库的 A019，真实环境升级后仍需做跨端验收。
